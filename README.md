# Reel Metrics WordPress Project

Custom WordPress theme with Elementor integration for the Reel Metrics website rebuild.

## Overview
This project contains a custom WordPress theme specifically designed for [Reel Metrics](https://www.reelmetrics.com/), featuring:

- Custom Elementor widgets and templates
- Modern WordPress theme architecture
- Figma design integration workflow
- Migration scripts for website transition
- Build tools for asset compilation

## Project Structure
```
rm-wordpress/
├── wp-content/themes/rm-elementor-theme/  # Main theme files
├── figma-exports/                         # Design assets from Figma
├── migration-scripts/                     # Database migration utilities
├── assets/                               # Global project assets
└── documentation/                        # Project documentation
```

## Theme: RM Elementor Theme
A hybrid WordPress theme that combines traditional WordPress functionality with Elementor page builder integration.
